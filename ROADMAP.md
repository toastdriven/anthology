# Roadmap

What follows is a rough/early roadmap of the features I have planned for
Anthology, up to the `1.0.0` release. No guarantees, just a basic plan/guide.

## 0.1.0

* Base SearchEngine implementation
* Establish plugin-patterns for the processors/tokenizers/etc.
* In-Memory Index
* In-Memory Document Store
* JSON-based Index
* JSON-based Document Store
* Basic HTML Preprocessor
* HTTP Server
* Simple Stemmer/Tokenizer
* Simple (straight popularity) Scoring
* Register the package

## 0.2.0

* SQLite-based Index
* SQLite-based Document Store
* Flat-file Document Store

## 0.3.0

* Simple Query Handling
* ??? Scoring

## 0.4.0

## 0.5.0
